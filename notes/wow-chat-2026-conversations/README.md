# The Conversations That Built the Client (copies)

The client in this project was first built inside wow-chat-2026, as its
"custom client" (issue 173 and its sub-issues there), from 2026-10-04 to
the move here on 2026-10-07 (wow-chat-2026 issue 173v). These are copies
of the conversations from those days, for reference: why a design is the
way it is, the owner's words, what was tried.

**They are copies, frozen on 2026-10-07.** They are kept outside this
project's `llm-transcripts/` on purpose: the transcript tools file each
conversation by the project its session ran in, and these ran in
wow-chat-2026. The days' conversations also hold that project's other
work (buddies, profiles, caves), mixed in.

**For the living versions, look there:**
`/mnt/mtwo/games/azeroth-core/wow-chat-2026/llm-transcripts/`. That is
where they are kept current (the last day's were still being written
when copied), rebuilt when the exporter improves, linked from the
completed issues, and turned into HTML pages by the transcript-care
tools (`/home/ritz/programming/ai-stuff/skills/`, "transcript-care"). Make
or read the HTML there, not from these copies.
